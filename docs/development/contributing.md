# Contributing

We welcome contributions! Please see CONTRIBUTING.md for the full guide.

## Quick guidelines

- Fork the repo and create a feature branch from `develop`
- Run `make lint` and `make test` before submitting
- Keep commits atomic with descriptive messages
- Update documentation for any changed behaviour
- Submit a pull request against `develop`

## Code style

- Rust: follow `rustfmt` defaults and `clippy` lints
- Python: follow PEP 8, use `ruff` for formatting
- TypeScript: follow Prettier defaults
- All: no trailing whitespace, 2-space indentation for YAML/JSON
